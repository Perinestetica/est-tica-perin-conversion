# Estética Perin Conversion

Crie uma landing page PROFISSIONAL, MODERNA, ELEGANTE E EXTREMAMENTE FOCADA EM CONVERSÃO para uma clínica de estética chamada:

ESTÉTICA PERIN

Profissional responsável:

ANA PAULA

Localização:

SANTO ANDRÉ - SP

OBJETIVO PRINCIPAL DA LANDING PAGE:

Gerar o máximo possível de cliques no botão do WhatsApp e transformar visitantes vindos de anúncios do Instagram/Facebook em agendamentos de limpeza de pele.

IMPORTANTE:

Esta landing page NÃO deve parecer um site institucional tradicional.

Ela deve funcionar como uma página de vendas de alta conversão.

O visitante provavelmente chegará através de um anúncio no Instagram ou Facebook, portanto a página precisa ser extremamente rápida, visual, objetiva, persuasiva e pensada PRIMEIRO PARA CELULAR.
